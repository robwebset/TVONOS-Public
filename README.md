# TVONOS Public Information

Welcome to TVONOS. This repository is to support the Android and Amazon TVONOS App.

For details about the App, you can visit the official website:

https://www.deadldyduck.com

TVONOS is currently supported on:
* Android TV - OS version 9 (Pie) and above
* Amazon Fire - [OS version 7 and above](https://developer.amazon.com/docs/fire-tv/fire-os-overview.html)

Downloadable onto your device from:
* Google Play: https://play.google.com/store/apps/details?id=com.deadlyduck.tvonos
* Amazon Store: http://www.amazon.com/gp/mas/dl/android?p=com.deadlyduck.tvonoslegacy

For older versions of Amazon Fire OS there is a legacy version available:
http://www.amazon.com/gp/mas/dl/android?p=com.deadlyduck.tvonoslegacy

To follow the status of TVONOS or to discuss any issues or ideas you can visit:
https://www.reddit.com/r/TVONOS/

Alternatively, if you find a problem or have an idea please share by raising an Issue (please check if there is already one before raisng anything new)
